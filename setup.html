Install the remote

Installing puts the remote on your home screen, full screen, without the browser bar. Your phone has to trust this Pi once so the remote can run over HTTPS.

On Android, install from Open https://192.168.0.48

iPhone and iPad

  1. In Safari, download the profile: Download profile and tap Allow.
  2. Open Settings, tap Profile Downloaded near the top, then Install.
  3. Go to Settings › General › About › Certificate Trust Settings and turn on Living Room Remote Local CA. Without this switch, HTTPS fails.
  4. Open https://remote.local in Safari.
  5. Tap Share › Add to Home Screen, keep Open as Web App on, then Add.

Android

Install from the Pi's address. Chrome won't install from remote.local on Android, only bookmark it.

  1. Download the certificate: Download certificate
  2. Open Settings and search for CA certificate. On most phones it is under Security › More security settings › Encryption & credentials › Install a certificate › CA certificate. Tap Install anyway and pick the downloaded file.
  3. Fully close Chrome, then open https://192.168.0.48. You should see no warning page.
  4. Open the ⋮ menu and tap Install app.

If your router ever gives the Pi a different address, reserve 192.168.0.48 for it in the router settings.

Certificate fingerprint

To confirm you installed the right certificate, its SHA-256 fingerprint starts with 42:37:FA:68 and ends with 31:F3:7A:D7.
